# cantrends

<!-- badges: start -->

[![R-CMD-check](https://github.com/mattwarkentin/cantrends/actions/workflows/R-CMD-check.yaml/badge.svg)](https://github.com/mattwarkentin/cantrends/actions/workflows/R-CMD-check.yaml)
<!-- badges: end -->

The goal of `cantrends` is to fit segmented line regression models
(i.e., piecewise linear spline models) to estimate trends in time-series
cancer incidence and mortality data.

To install `cantrends`, run the following code:

``` r
remotes::install_github('mattwarkentin/cantrends')
```
